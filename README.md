# KOFIC Lounge Stamp 🎞️

> 제31회 부산국제영화제(BIFF) 2026 **영화진흥위원회(KOFIC) 라운지**에서 운영했던 **모바일 디지털 스탬프 투어** 웹 페이지입니다.

> ℹ️ 이 저장소는 **행사 종료 후 보관(아카이브) 목적**으로 공개되어 있습니다. 현재 행사는 운영되지 않으며, 코드에 포함된 부스 정보·암구호·PIN은 당시 행사용 값입니다.

종이 스탬프판 없이 관람객이 자신의 스마트폰으로 부스를 돌며 도장을 모으고, 5개를 모두 모으면 현장 스태프 확인을 거쳐 사은품을 받는 방식이었습니다. 별도 앱 설치 없이 QR 코드로 접속하는 **단일 HTML 파일** 기반 서비스로 제작했습니다.

## 프로젝트 배경

- 영진위 부스 운영 과정에서 종이 스탬프판을 대체하고, 관람객이 편하게 참여할 수 있는 방식을 고민하며 직접 구현했습니다.
- 생성형 AI (Claude) 를 활용한 프로토타이핑(바이브코딩)으로 HTML 페이지와 구글 시트 연동을 구성했습니다.
- 도장을 단순 체크 표시가 아닌 **위원회 캐릭터 이미지**로 제작하고, 부스별로 특색 있는 암구호를 정할 수 있게 했습니다.
- 현장 스태프 확인 단계를 두어 **사은품 중복 수령을 방지**했고, 종이 인쇄물을 줄여 **페이퍼리스 운영**에 기여했습니다.

## 주요 기능

- **부스별 암호 인증** – 각 부스를 체험한 뒤 안내받은 암구호를 입력하면 도장이 찍힙니다.
- **도장 획득 연출** – 부스별 캐릭터 도장 이미지(PNG)가 팝업 애니메이션으로 나타나고, 이미 획득한 부스를 다시 누르면 도장을 확인할 수 있습니다.
- **진행도 표시** – `진행도: n / 5` 상태 박스와 부스별 체크 표시로 진행 상황을 한눈에 확인할 수 있습니다.
- **스태프 확인 기반 사은품 수령** – 5개를 모두 모으면 수령 버튼이 활성화되고, 스태프 PIN 입력으로 지급 완료 처리됩니다. 처리 후에는 재수령 및 추가 참여가 불가능합니다.
- **구글 시트 기록** – 도장 획득과 사은품 수령 내역이 Google Apps Script 웹 앱을 통해 구글 시트에 쌓여 참여 현황을 집계할 수 있었습니다.

## 부스 구성

| # | 부스 | 미션 |
|---|------|------|
| 1 | 공정성장센터 | 이벤트 안내 받고 다른 부스도 둘러보기 |
| 2 | 시·청각장애인 영화관람지원 서비스 '가치봄' | 부스에서 퀴즈 맞추기 |
| 3 | 영화인신문고 | 영화인신문고 사업 알아보기 |
| 4 | 한국저작권보호원 | 공식 인스타그램 팔로우 인증 |
| 5 | 한국영화성평등센터 든든 | 공식 인스타그램 팔로우 인증 |

사은품 수령처는 **공정성장센터 부스**였습니다.

## 기술 스택

- **Frontend**: HTML / CSS / Vanilla JavaScript (프레임워크·빌드 과정 없음)
- **상태 저장**: 브라우저 `localStorage` (참여자 ID, 획득한 도장, 수령 여부·시각)
- **데이터 수집**: Google Apps Script 웹 앱 + Google Sheets
- **접속**: QR 코드

## 동작 흐름

1. 관람객이 QR 코드로 접속하면 `localStorage`에 임의의 참여자 ID(`user_xxxxxxx`)가 발급됩니다.
2. 부스 카드를 눌러 위치·미션을 확인하고, 미션 수행 후 부스 암구호를 입력합니다.
3. 암구호가 맞으면 도장이 등록되고 구글 시트에 `{ userId, boothName }`이 전송됩니다.
4. 5개를 모두 모으면 **사은품 수령하기** 버튼이 나타납니다.
5. 스태프에게 화면을 보여주고 스태프 PIN을 입력하면 **수령 완료** 처리됩니다.

## 다른 행사에 활용하려면

`index.html` 하단 `<script>` 상단의 값을 바꾸면 다른 행사에도 쓸 수 있습니다.

| 항목 | 설명 |
|------|------|
| `GOOGLE_SCRIPT_URL` | 본인의 Apps Script 웹 앱 URL (비워 두면 시트 기록 없이 동작) |
| `STAFF_PIN` | 사은품 지급 확인용 스태프 PIN |
| `booths` | 부스 이름, 암구호(`pass`), 안내 문구(`desc`), 도장 이미지(`stampImg`) |

### 구글 시트 연동 (예시)

1. 구글 시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. 아래와 같은 `doPost` 함수를 작성합니다.

   ```javascript
   function doPost(e) {
     const data = JSON.parse(e.postData.contents);
     SpreadsheetApp.getActiveSheet()
       .appendRow([new Date(), data.userId, data.boothName]);
     return ContentService.createTextOutput("ok");
   }
   ```

3. **배포 → 새 배포 → 웹 앱**으로 배포(액세스: 모든 사용자)한 뒤, 발급된 URL을 `GOOGLE_SCRIPT_URL`에 넣습니다.

> 재사용 시 참고: 암구호와 스태프 PIN이 클라이언트 코드에 포함된 구조이고, 진행 상태는 브라우저 `localStorage`에 저장됩니다. 소규모 현장 행사용 경량 구현이므로, 보안이 중요한 용도라면 서버 측 검증을 추가하세요.
